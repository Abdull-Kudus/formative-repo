## Getting Started

### 1. Environment Setup

```bash
# Clone the repository
git clone <YOUR_REPO_URL>
cd formative-repo

# Create and activate virtual environment
python -m venv .venv

# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate

# Install required dependencies
pip install -r requirements.txt
```

### 2. Launching Notebooks

```bash
jupyter notebook
```
Navigate to `notebooks/` and open your assigned notebook.

## Assignment Modules

### Part 1 — Probability Distributions: EM Algorithm (Mixture of Gaussians)
- **Notebook:** `notebooks/Part1_Probability_Distributions_EM_Algorithm.ipynb`
- **Owner:** Member 1
- **Dataset:** `data/GaltonFamilies.csv`
- **Goal:** Fit a two-component Gaussian Mixture Model using Expectation-Maximization (EM) without using labeled components. Compare convergence against a simple split at the global mean.

### Part 2 — Bayesian Probability (IMDb Movie Reviews)
- **Notebook:** `notebooks/Part2_Bayesian_Probability_IMDb_Reviews.ipynb`
- **Owner:** Member 2
- **Dataset:** `data/IMDB_Dataset.csv.gz`
- **Goal:** Calculate prior $P(\text{Positive})$, likelihood $P(\text{keyword} \mid \text{Positive})$, and posterior $P(\text{Positive} \mid \text{keyword})$ for key sentiment indicators using pure Python (`csv`, `gzip`, `string`).

### Part 3 — Gradient Descent Manual Calculation (Handwritten)
- **Deliverable:** `docs/Part3_Gradient_Descent_Manual_Calculation_Handwritten.pdf`
- **Owner:** Member 3 (setup, derivation, Update 1), Member 1 (Update 2), Member 2 (Update 3 + summary)
- **Goal:** Perform manual step-by-step matrix updates for linear regression using Mean Squared Error cost and learning rate $\alpha = 0.01$.

### Part 4 — Gradient Descent in Code (Python + SciPy)
- **Notebook:** `notebooks/Part4_Gradient_Descent_in_Code.ipynb`
- **Owner:** Member 3
- **Goal:** Implement the hypothesis and MSE cost function, verify numerical derivatives using `scipy.differentiate` against analytical chain-rule formulas, and reproduce the Part 3 manual updates.
